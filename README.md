# MeshThumbs

3D model thumbnails for Windows Explorer, with textures, vertex colors, and automatic framing.

**Supported formats**

`OBJ` · `FBX` · `GLB` · `glTF` · `STL` · `DAE` · `PLY` · `3DS` · `3MF` · `VRM` · `BLEND`

![MeshThumbs thumbnail examples](docs/images/meshthumbs-preview.png)

## Install

Download the `.msi` installer from the latest release and run it to install or upgrade. Uninstall through **Windows Settings → Apps → Installed apps**.
